# 法务与风险说明

> 本文不是法律意见。公开发布前建议律师复核。

## 1. 范围

- 仅限**本人拥有的设备**，或**所有人在场并明确同意**的协助；
- 禁止租赁、酒店/公共场所设备、所有人不在场的远程代操作；
- 不 root、不卸载、不刷机、不碰桌面/代理/影视源/DRM/盗版。

## 2. 免责声明能做什么 / 不能做什么

| 能做到 | 做不到 |
|--------|--------|
| 证明已告知风险 | 免除故意/重大过失责任 |
| 降低用户预期 | 对抗消费者权益/侵权强制规定 |
| 纠纷中帮助举证 | 阻止厂商投诉、平台下架 |
| 让理性用户自行判断 | 阻止用户起诉/索赔 |

**免责声明不是免死金牌。** 最有效的风控是范围门禁 + 安全设计 + 非商业 + 可回滚。

## 3. 相关条文（摘要）

- 《民法典》496：格式条款提示说明义务；未履行，对方可主张条款不成为合同内容。
- 《民法典》497：不合理免责/加重对方责任/限制或排除对方主要权利的格式条款无效。
- 《民法典》506：造成人身损害、因故意或重大过失造成财产损失的免责条款无效。
- 《反不正当竞争法》（2025-10-15 施行）第 13 条：规制**经营者**利用网络妨碍、破坏其他经营者合法提供的网络产品或服务正常运行；第 2 条把经营者定义为从事商品生产、经营或提供服务的自然人/法人/非法人组织。个人非商业自用通常不满足「经营者 + 竞争关系」，但**收费代客、分发工具**的风险更高。
- 《消费者权益保护法》第 26 条：经营者不得以格式条款排除/限制消费者权利、减轻/免除自身责任。
- 《刑法》285/286：非法侵入/控制、破坏计算机信息系统；286 以「后果严重」为门槛。本人设备 + 授权 + 可逆 + 不 root/卸载，通常不满足；「提供工具」条款外延较宽，仍有低概率争议。
- 广电总局《公共场所电视服务提升实施指南》（广电办发〔2026〕1 号）：适用**公共场所**，不是家庭电视，也不是家用去广告的授权依据；小米官方关闭开机广告通道为 950816 + 以太网/WiFi MAC（以小米客服口径为准）。

## 4. 公开案例（供理解风险，不是判例支持）

- 江苏消保委诉乐融（南京中院 (2020)苏01民初62号、江苏高院 (2021)苏民终21号）：判厂商须提供开机广告「一键关闭」。这说明用户想关开机广告有消费者权益基础，**不等于第三方工具被授权**。
- ADsafe 净网大师案（上海知产法院 2016-08）：商业广告拦截工具被判不正当竞争，赔偿 23 万+12 万+12 万。区别在于商业产品、网络层拦截、损害商业模式；本项目免费、本人设备、可逆、只动系统组件——**但不能据此说零风险**。
- 未找到「个人/开源电视去广告工具被厂商起诉」的公开案例（**未证实**）；不要在 README 里暗示有判例支持。

## 6. 被投诉/下架

2. 区分平台投诉与法院认定；
3. 评估性质，不硬扛；
4. 按平台流程申诉/整改，必要时下架并说明；
5. 用户通知（README/issue）；
6. 复盘并更新文档。
